# Interactive Regression Visualizer (Shiny)

Live Demo: [Open App](https://jadoon.shinyapps.io/lab3/)

This project builds an interactive Shiny application for exploring simple linear regression relationships using the mtcars dataset.

## App Preview

<img src="https://github.com/user-attachments/assets/9685ee95-7f87-4529-bc4b-6c897a6a1a61" width="900">

## Features

- Select X and Y variables dynamically
- Toggle regression line display
- Choose regression type (Linear or LOESS)
- Adjust point opacity
- Interactive plot using Plotly
- Display regression equation and R²

## Tools

- R
- Shiny
- ggplot2
- plotly

## Model

Simple Linear Regression
